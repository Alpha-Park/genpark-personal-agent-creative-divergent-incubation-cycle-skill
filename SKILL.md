# Personal Agent Creative Divergent Incubation Cycle Skill

Designed for **OpenClaw**, **Hermes**, and autonomous personal AI agents to orchestrate human creative breakthroughs, detecting prefrontal executive cognitive fixation and scheduling Default Mode Network (DMN) associative incubation periods.

## Agent In-Context Capabilities

- **Graham Wallas Creativity Framework**: Formulates transitions across Preparation, Incubation, Illumination, and Verification.
- **Cognitive Impasse Detection**: Prevents counter-productive brute-forcing when continuous linear focus exceeds 75-90 minutes and semantic search spaces narrow.
- **DMN Spreading Activation Scheduling**: Prescribes low-cognitive-demand tasks (unhurried walking, warm showers) that liberate subconscious combinatorial insight.

## Tools Summary

1. `evaluate_incubation_necessity`: Calculates fixation index and DMN activation potential.
2. `schedule_unconscious_incubation_window`: Prescribes specific incubation activities and strict cognitive blackout constraints.
